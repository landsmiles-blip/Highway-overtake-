# Embedded fonts

Embedded in `gate-highway-prototype.html` (line 13, about 90 KB) so the game makes no outside calls, which YouTube Playables forbids. Search that file past line 337 only.

| Font | File | Licence | Note |
|---|---|---|---|
| Orbitron | `Orbitron-wght.ttf` | SIL OFL 1.1, Reserved Font Name "Orbitron" | Unmodified original from [google/fonts](https://github.com/google/fonts/tree/main/ofl/orbitron). Not subset, because the licence restricts modified versions from using the reserved name |
| Rajdhani | `Rajdhani-500/600/700.woff2` | SIL OFL 1.1, no reserved name | Printable ASCII subset from Google Fonts |

The licence texts are the `OFL-*.txt` files here. They must ship with any release build.
